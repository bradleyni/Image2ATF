Welocalize DTP 图片准备工具 V2.8

Welocalize DTP 图片准备工具集成了 Google Gemini 与 Anthropic Claude 模型，并支持调用 Adobe 软件 COM 接口。主要用于辅助完成图片文本提取、背景处理、图层重构及双语文件生成等自动化排版准备工作。

2. 基本设置与视图控制

网络与密钥配置 使用对应功能前，请在界面顶部输入 API Key。若处于受限网络环境，请勾选 Use Proxy 并确认代理地址。配置信息会自动保存。

图片预览操作：

  • Ctrl + 鼠标滚轮：放大/缩小图片。
  • 鼠标滚轮：在图片放大状态下进行上下平移。
  • Delete：从左侧列表中移除选中的文件。

3. 常规全文 OCR （已隐藏）

适用于排版结构简单、无冗余视觉干扰元素的图片文本提取。

  • 点击 Add Files 导入目标图片。
  • 点击 Auto Rotate（自动旋转）或使用 ↺ / ↻ 按钮，确保文本呈水平方向。
  • 点击 Start OCR 开始处理。程序将并发提取文本。
  • 在右侧 OCR RESULT 区域核对并修改识别结果。
  • 点击 Generate ATF 导出。完成后系统将尝试自动打开生成的 Word 文档。
说明： 常规 OCR 会提取图像内所有可见文本。若图纸中包含大量无需翻译的标注或数据，建议使用遮罩模式。

4. Mask 遮罩模式 (Tab 3)

适用于排版复杂、文本倾斜或包含无需翻译内容的图片。通过手动指定提取区域，约束 AI 的识别范围与段落合并方式。

  • 导入图片，并自动或手动调整至水平方向，以提高 OCR 准确度。
  • 点击 AI 批量画框，运行 AI 初步文本块定位。
  • 手动调整或绘制提取区域，支持以下鼠标操作：
    左键拖拽：绘制矩形提取框。
    左键单击：逐点描边绘制多边形，最后通过双击或右键闭合，适用于不水平或垂直文本。
    右键拖拽：绘制红色擦除区域，删除接触到的提取框。
  • 点击 Start OCR。系统将依据选定区域输出带有序号的文本段落。
    单图OCR：如果单图调整了画框，可以点击“重新识别”来单独提取。
    失败重试：如果因网络原因导致某些图片OCR失败，可以再次点击“开始OCR”按钮，程序仅对失败的图片进行重试。
  • 检查结果后点击 生成 ATF 导出文件。

5. 静态图生成 PSD

将包含文字的静态位图（JPG/PNG）转换为文字背景被擦除、且包含可编辑文本图层的 Photoshop 文件。

  • 导入图片，使用与 "Mask 模式“标签页相同的操作框选需要重建的文本区域。请确保选框贴合文字且未包含复杂的背景图形。为了文本框位置的精度，此功能区下不提供图片旋转和多点不规则形状蒙版绘制。
  • 调整文本对齐方式：遮罩生成的时候会判断文本对齐方式并在蒙版上以“L”（左对齐），“R”（右对齐）或者“C”（居中对齐）来表示。
    左键点击选框：在 [L] 左对齐、[C] 居中对齐、[R] 右对齐 之间切换。
  • 在右侧工具栏的 Base Font 下拉菜单中搜索并选择目标排版字体（支持输入过滤，默认为 Arial）。
  • 点击 创建 PSD。
  • 程序将调用后台的 Photoshop 执行内容识别填充及图层生成，请等待流程结束。
    注意： Photoshop中不要有打开并且处于编辑状态的窗口。
    创建的PS文件包含文本图层，以及三个背景图层：原图、AI 抹除背景图和“内容识别填充”恢复的背景图。
    对于透明背景的 PNG 图片，则仅生成原图层和剪切掉文字区域的新透明背景图层。
注意事项： 系统需安装 Adobe Photoshop，且运行期间 Photoshop 必须处于空闲状态（无未处理的弹窗或对话框）。生成的 PSD 文件内包含一个隐藏的原始参考图层，可用于校对位置。
已知特性： 1. CMYK 颜色图片因为 AI 仅支持 RGB，因此重绘的背景图层会有一定色差。
2. 文本框大小严格遵循画框蒙版，若选择的字体过大，可能会导致文字溢流。
3. 文字图层的字号通过高度计算得出，可能与原图字号存在差异。

6. PSD/AI 文本导出和导入 (Tab 5)

支持批量解析 PSD 或 AI 源文件中的文本图层，并支持翻译后的自动导回与假翻排版检查。

  • 提取文本： 导入 .psd 或 .ai 文件。可勾选 假翻 (Pseudo) 选项。点击 Export 后，系统将按源文件名称独立生成双语对照文件（PSD 生成 Word 格式，AI 生成 XLF 格式）。
    注：若勾选了假翻选项，系统还会额外生成一份去除了图层、嵌入字体的 PDF 参考文件，其中的文字会被统一替换为占位符 (X/x/0)，用于检查排版布局或文本截断。
  • 进行外部翻译作业。
  • 导回文本： 确保列表中存在对应的源文件，点击 Import Translation 并选择已翻译好的文件（支持批量选择）。程序将根据文件名称自动匹配并更新源文件的文本内容。
格式支持说明：
Photoshop (.psd)：受限于 COM 接口，导出的 Word 无法存储单一图层内的混合样式（如同一句话部分加粗），翻译后需在 PS 中手动核对局部样式。
Illustrator (.ai)：通过基于 XML 标签的分片解析机制，支持保留并还原文本内局部的加粗、颜色、斜体及上下标等富文本属性。

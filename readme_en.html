Welocalize DTP Image Preparation Tool V2.8

The Welocalize DTP Image Preparation Tool integrates Google Gemini and Anthropic Claude models, and supports calling Adobe software COM interfaces. It is mainly used to assist in automated desktop publishing preparation tasks, including image text extraction, background processing, layer reconstruction, and bilingual file generation.

2. Basic Settings & View Controls

Network and API Configuration Before using the corresponding features, please enter the API Key at the top of the interface. If operating in a restricted network environment, check Use Proxy and confirm the proxy address. Configuration settings are saved automatically.

Image Preview Operations:

  • Ctrl + Mouse Wheel: Zoom in/out of the image.
  • Mouse Wheel: Pan vertically when the image is zoomed in.
  • Delete: Remove the selected files from the list on the left.

3. Standard Full-text OCR (Hidden)

Suitable for extracting text from images with simple layout structures and no redundant visual interference elements.

  • Click Add Files to import target images.
  • Click Auto Rotate or use the ↺ / ↻ buttons to ensure the text is oriented horizontally.
  • Click Start OCR to begin processing. The program will extract text concurrently.
  • Verify and modify the recognition results in the OCR RESULT area on the right.
  • Click Generate ATF to export. Once complete, the system will attempt to automatically open the generated Word document.
Note: Standard OCR extracts all visible text within the image. If the drawing contains a large amount of annotations or data that do not require translation, using Mask Mode is recommended.

4. Mask Mode (Tab 3)

Suitable for images with complex layouts, slanted text, or content that does not require translation. By manually specifying the extraction areas, you constrain the AI's recognition scope and paragraph merging method.

  • Import the image and automatically or manually adjust it to a horizontal orientation to improve OCR accuracy.
  • Click Batch AI Auto-Box to run the initial AI text block positioning.
  • Manually adjust or draw extraction areas using the following mouse actions:
    Left-click & Drag: Draw a rectangular extraction box.
    Left-click Points: Click sequentially along edges to draw a polygon, then double-click or right-click to close it. Suitable for non-horizontal or non-vertical text.
    Right-click & Drag: Draw a red erasure area to delete any extraction boxes it touches.
  • Click Start OCR. The system will output numbered text paragraphs based on the selected areas.
    Single Image OCR: If you adjusted boxes on a single image, click "Re-OCR" to process it again.
    Retry Failed: If OCR fails for certain images due to network issues, click the "Start OCR" button again to retry only the failed images.
  • After verifying the results, click Generate ATF to export the file.

5. Static Image to PSD (Tab 4)

Converts static bitmaps (JPG/PNG) containing text into Photoshop files with the text background erased and editable text layers generated.

  • Import the image and use the same actions as the "Mask Mode" tab to box the text areas needing reconstruction. Ensure the box aligns closely with the text and does not include complex background graphics. To ensure text box position accuracy, image rotation and multi-point irregular masking are disabled in this feature area.
  • Adjust text alignment: When the mask is generated, the text alignment is determined and represented on the mask as "L" (Left-aligned), "C" (Center-aligned), or "R" (Right-aligned).
    Left-click Box: Toggle between [L] Left, [C] Center, and [R] Right alignment.
  • Search and select the target layout font in the Base Font dropdown menu (defaults to Arial).
  • Click Build PSDs.
  • The program will call Photoshop in the background to execute content-aware fill and layer generation. Please wait for the process to complete.
    Note: Ensure there are no open and active editing windows/dialogs in Photoshop.
    The created PS file contains text layers and three background layers: the original image, an AI-erased background layer, and a background restored using "Content-Aware Fill".
    However, for PNG images with transparent backgrounds, only the original layer and a new background layer with the text area cut out are generated.
Important Considerations: Adobe Photoshop must be installed on the system and must remain idle (without unhandled pop-ups or dialogs) during execution. The generated PSD file includes a hidden original reference layer, which can be used for position alignment and proofreading.
Known Characteristics: 1. Because AI only supports RGB, CMYK color images will exhibit color differences in the redrawn background layers.
2. The text box size strictly conforms to the drawn mask; selecting an oversized font may result in text overflow.
3. The font size of the text layer is calculated mathematically based on height and may differ from the original image.

6. PSD/AI Text Export & Import (Tab 5)

Supports batch parsing of text layers from PSD or AI source files, and supports automatic re-import after translation and layout checking via pseudo-translation.

  • Extract Text: Import .psd or .ai files. Check the Pseudo option if necessary. Click Export, and the system will generate individual bilingual files named after each source file (Word format for PSD, XLF format for AI).
    Note: If the "Pseudo" option is checked, the system will also generate an additional minimal-sized PDF reference file with embedded fonts, where the text is replaced by placeholders (X/x/0) to check for layout issues or text truncation.
  • Proceed with external translation assignments.
  • Import Text: Ensure the corresponding source files exist in the list. Click Import Translation and select the translated files (batch selection supported). The program will automatically match the filenames and update the source file's text content.
Format Support Notes:
Photoshop (.psd): Due to API limitations, the exported Word file cannot store mixed styles within a single layer (e.g., partial bolding). Manual style verification in PS is required after translation.
Illustrator (.ai): Utilizes an XML tag mechanism, supporting the retention and restoration of bold, color, italics, and sub/superscript attributes within the text.
